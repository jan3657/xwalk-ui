Turn biomedical text into ontology IDs

Paste a sentence. Claude finds the chemicals, diseases and foods in it, and xwalk links each one to a term in ChEBI, MeSH or FoodOn.

Searches more than 260,000 real ontology terms. Every ID comes from the ontology; the model never writes one.

          Run details

          That lookup is xwalk

          The model never writes an ID. xwalk looked up each mention by keyword and by meaning, and the model chose among real candidates. The catalog holds more than 260,000 terms. xwalk is an open-source Python library; you can run the same lookup on your own vocabulary.

          xwalk on GitHub

          How this site handles data

          • Your text is sent to the model provider to find the mentions and choose the terms: Anthropic by default; OpenRouter, and the model host it routes to, if the run falls back or you choose it; the provider of your own key if you use one.
          • When embedding search is used, the mentions found in your text are sent to OpenRouter to compute search embeddings. The server may keep recent mentions, search results and answers in memory for a few hours so that it does not compute them twice; none of that is written to its database.
          • This site is built not to keep your text, prompt or results: its logs and its database are designed to hold run metadata only, for example time, model, token counts and country, and a visitor hash that changes every day.
          • When run recording is enabled, this site attempts to save one row of that metadata for each run.
          • Runs on this site's own models are limited per network, and runs with your own key are counted the same way, using a salted hash of the IP address. Entries older than a day are deleted by a clean-up that runs from time to time.
          • Visits are counted without cookies.
          • If you use your own API key, it stays in this browser tab's session storage and is sent only with your runs.
