Turn biomedical text into ontology IDs

Paste a sentence. Claude finds the chemicals, diseases and foods in it, and xwalk links each one to a term in ChEBI, MeSH or FoodOn.

Searches more than 260,000 real ontology terms. Every ID comes from the ontology; the model never writes one.

          Run details

          That lookup is xwalk

          The model never writes an ID. xwalk searched more than 260,000 ontology terms by keyword and by meaning, and the model chose among real candidates. xwalk is an open-source Python library; you can run the same lookup on your own vocabulary.

          xwalk on GitHub

          How this site handles data

          • Your text is sent to the model provider for extraction and term choice: Anthropic by default, OpenRouter if the run falls back or you choose it.
          • The extracted mentions are sent to OpenRouter to compute search embeddings.
          • This site stores no text, prompt or result. Each run is counted (time, model, token counts, country) without the text.
          • Requests are limited per network, using a salted hash of the IP address that is kept for one day.
          • Visits are counted without cookies.
          • If you use your own API key, it stays in this browser tab's session storage and is sent only with your runs.
